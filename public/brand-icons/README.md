# Brand asset sources

The SVG subset is stored locally, with content-hashed filenames. No font CDN,
third-party API request or entire icon collection is loaded at runtime.

- Programming languages and frameworks: Devicon v2.17.0 (MIT), official devicons/devicon repository.
  The original MIT notice is preserved in DEVICON-LICENSE.txt.
- Brands: Simple Icons, commit 98820a4dc8c363ca72fa2c0d294ea4a0a9bba75d (CC0 collection), official simple-icons/simple-icons repository.
- LinkedIn uses the Devicon asset because it is not present in the selected Simple Icons collection.
- Missing source brands remain readable text. Do not draw replacement "official" logos or use a language logo for an employer.
- These logos are for identification; trademarks and individual brand usage guidelines still apply. Collection licensing does not grant employer-photography reuse rights.

Company photographs and logos come only from the backend's permission-aware
company entity. They are not looked up in this technology-icon registry.
